my long beloved merios Lerios is now publically avaliable for downloading on github

**What is it?**

merios Lerios (or known as Marios Windows Zone) is an Windows Zone mod replacing Sonic with Mario, especifically Mario from SMB1.



**Requirements**:
DirectX 10 Runtime;

dotNET Franework 3.5 (can be installed via the optional features on Windows);

Windows 7+ (right now, linux support isnt avaliable)
